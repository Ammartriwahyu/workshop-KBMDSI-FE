# Kunci Jawaban — freeCodeCamp Clone

Folder ini berisi project lengkap hasil akhir workshop (tanpa `node_modules/` dan `.next/`). Pakai untuk membandingkan kalau hasilmu berbeda. Panduan lengkapnya ada di [README utama](../README.md).

Cara menjalankan (dari terminal, di dalam folder `hasil-akhir`):

```bash
npm install
```

```bash
npm run dev
```

Lalu buka http://localhost:3000.

> Proyek ini hanya untuk latihan belajar slicing dan tidak berafiliasi dengan freeCodeCamp. Logo dan foto asli tidak digunakan.
